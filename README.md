# Gerador de Recibo

Gerador de recibos simples feito pro meu pai: edite os campos direto na tela, o valor por extenso é preenchido automaticamente e o recibo pode ser impresso ou salvo em PDF.

### 👉 [lauroseibert.github.io/gerador-recibo](https://lauroseibert.github.io/gerador-recibo/)

<img width="1800" height="1298" alt="screenshot" src="https://github.com/user-attachments/assets/610cd75e-3bf1-41a9-861a-1075e5b19ed8" />

## Como funciona

- Clique em qualquer campo do recibo (número, valor, nome, descrição, cidade, data e assinatura) para editar.
- Ao digitar o valor, o campo "A quantia de" é preenchido por extenso.
- O botão **Imprimir / Salvar PDF** gera o recibo pronto.
